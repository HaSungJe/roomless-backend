roomless 이용자 화면

무인 객실 대여 서비스 이용자 화면 25장을 화면 지침서(screens.md) 순서대로 위에서 아래로 이어 본다. 화면마다 머리줄에 키 · 시안 이름 · 주소를 적었고, 화면 안 정보 · 버튼 · 문구는 지침서와 DTO 필드를 따른다. 시안 안 링크 · 탭 중 다른 화면으로 가는 것은 이 페이지의 그 화면으로 이동한다. 업체 · 사람 · 번호 같은 예시 값은 모두 지어낸 것이다.

화면 규칙

  • 화면 하나 = 휴대폰 화면 하나, 너비 390px. 긴 화면은 스크롤 화면을 펼쳐 그린 것이다. 기기 상태 표시줄은 그리지 않는다.
  • 주 탭 화면(U1 지도 · U6 내 예약 · U10 마이)은 아래에 하단 탭(지도 · 내 예약 · 마이), 하위 화면은 위에 상단 바(뒤로 가기 + 화면 제목).
  • 하단 고정 행동 버튼(예약하기 · 결제하기 · 연장 신청 …)은 52px 주 버튼.
  • 사진 · 지도 · QR 은 자리표시로 그렸다 — 실제 화면은 image_url · 지도 SDK · qr(32자)로 그린다.
  • 상태 · 종류 이름은 룩업 이름 그대로, 입력 오류는 DTO 메시지 그대로, 서버 실패는 message 그대로 보여 준다.
  • 날짜 · 시각은 한국 시각 "11월 10일(화) 14:30", 날이 넘어가면 끝에도 날짜를 쓴다. 금액은 "18,000원". 예시는 2026년 11월 10일(화) 오후 기준이다.

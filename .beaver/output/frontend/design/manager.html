콘솔 틀

왼쪽 메뉴 232px(대시보드 · 예약 현황 · 호실 · 객실 그룹 · 상품 설정 · 내 업체 설정 · 업체 관리자 — 마지막은 업체 총관리자(auth_id HEAD_MANAGER)에게만 보인다, 지금 화면 항목은 주색 옅게 바탕). 본문은 메뉴 옆 flex-wrap 줄(본문 flex: 999 1 560px)이라 좁으면 메뉴가 위로 쌓인다. 상단 바: 업체 이름 · 업체코드(내 업체 상세 store_name · store_code) · 로그인 아이디 + 권한 배지 · 비밀번호 변경 · 로그아웃(로그아웃 API 는 없다 — 저장한 토큰만 지운다). 넓은 표 · 타임라인은 각자 가로 스크롤 상자. 대화상자는 바탕을 rgba(21,23,26,0.45)로 덮고 흰 카드(모서리 12)를 위쪽 가운데에.

로그인 계열(M1)은 메뉴 없이 바탕 위 가운데 카드. 업체코드(32자 영문 소문자 · 숫자)는 사람이 치지 않고 로그인 주소(/manager/[store_code]/login)에 들어 있다 — 상단 바에는 앞 8자 + … 만 보이고, 전체와 로그인 주소 복사는 내 업체 설정 › 기본 정보에. 로그아웃하면 기억해 둔 업체 로그인 주소로 돌아간다.

로그인 · 계정

업체코드(store_code — 32자 영문 소문자 · 숫자, 예 3f9a2c7e5b1d4a8e9c0f6b2d7e4a1c21)는 사람이 치지 않고 주소에 들어 있다. 로그인 전 화면 3개는 주소의 [store_code] 를 그대로 API 에 넘기고 화면에서는 아이디 · 비밀번호 · 휴대폰만 받는다. 업체 관리자는 자기 업체 로그인 주소를 즐겨찾기하고, 로그인 뒤 화면은 /manager/… 그대로다(토큰이 업체를 안다).

M1 로그인

/manager/[store_code]/login

POST /api/v1/admin-service/manager/login(store_code = 주소 값 · login_id · login_pw) → 토큰 · auth_id · store_id 저장, 이 업체코드도 브라우저에 기억해 둔다(로그아웃 · 401 때 돌아갈 로그인 주소). 로그인 전에는 업체 이름을 읽는 API 가 없어 업체 이름을 띄우지 않는다.

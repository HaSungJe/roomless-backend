표기 규칙

  • 날짜 · 시각은 한국 시각 YYYY-MM-DD HH:mm(응답은 ISO 8601), 달은 YYYY-MM.
  • 금액은 천 단위 쉼표 + 원(18,000원). 표의 숫자 칸은 오른쪽 맞춤 · 고정폭 숫자.
  • 휴대폰 · 전화는 응답의 숫자를 010-1234-5678 · 02-555-0123 꼴로 끊어 보여 주고, 입력은 숫자만 받는다. 사업자등록번호는 120-88-45678 꼴.
  • 업체코드 · 검색 코드는 32자(영문 소문자 + 숫자)다. 목록은 앞 8자 + …(마우스를 올리면 전체), 상세는 전체 + 복사 버튼.
  • 값이 없으면(null) —. 상태 · 종류 · 권한 이름은 룩업 이름 그대로.
  • 큐 API(승인 · 반려 · 상태 변경 · 영업중 · 정보 수정 · 초기화 · 이용 제한 · 비밀번호 변경)는 누른 버튼을 "처리 중…" 으로 막는다. done 이면 성공 띠 + 다시 조회, failed 면 message(입력 칸 오류는 그 칸 아래), pending 이면 그 화면의 조회 API 를 다시 부른다.
  • 목록은 page · size 로 부르고, 거르기를 바꾸면 1쪽부터 다시 부른다. 목록 행의 이름 칸은 상세로 가는 링크.
  • 401 이면 재발급 API 로 한 번 재발급하고 다시 부르고, 또 401 이면 돌아올 주소를 들고 로그인 화면으로 간다. 로그아웃 API 는 없다 — 저장한 토큰을 지운다.
